# YWF Discord Bot (Archived)

This repository contains the source code for **YWF**, a Discord bot written using **Skript (Vixio)**.

The bot was originally created for a personal Discord server called **Young, Wild and Free**, with the goal of automating moderation tasks and adding interactive features for the community.

This project is no longer active and is kept here for **archival and learning purposes**.

---

## Project purpose
- Learn basic bot logic and automation
- Experiment with Skript and Vixio
- Automate common Discord server tasks
- Add simple interactive commands and utilities
- Explore event-based programming

---

## Technologies used
- **Skript**
- **Vixio**
- Discord (bot integration)

---

## What this repository contains
- Skript files related to the YWF Discord bot
- Automation logic for server management
- Command handling and event responses
- Experimental features and learning code

The code reflects the learning stage I was in at the time and may not follow best practices.
